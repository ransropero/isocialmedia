# Startup Instructions

## Production (Recommended for Deployment)
From the project root (`instagram-scheduler`), run:
```bash
npm start
```
This serves the application on port **5001**.
*Note: Make sure to run `npm install` first to build the client.*

## Development
To run in development mode with hot-reloading:
```bash
npm run dev
```
-   Server: `http://localhost:5001`
-   Client: `http://localhost:3000` (proxies to server)
